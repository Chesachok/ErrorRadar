## О проекте

**Error Radar** — расширение для Visual Studio Code, которое собирает диагностические сообщения, предоставляемые редактором и установленными языковыми расширениями, и отображает их в отдельной панели Explorer.

Расширение помогает просматривать ошибки и предупреждения в нескольких файлах, видеть текст сообщения и номер строки, а также быстро переходить к месту диагностики.

> **Использование ИИ:** при разработке проекта и подготовке документации использовался ИИ-ассистент для консультаций, поиска и исправления ошибок, объяснения API VS Code и подготовки отдельных фрагментов кода и текстовых материалов.

## Возможности

- отображение файлов, в которых есть диагностики;
- группировка сообщений по файлам;
- отображение количества диагностик рядом с именем файла;
- отображение текста диагностики, номера строки и значка типа сообщения;
- автоматическое обновление дерева при изменении диагностик в VS Code;
- переход к соответствующему месту в исходном файле по нажатию на диагностику;
- подсчёт ошибок, предупреждений и информационных сообщений в активном файле через команду `Error Radar: Check Diagnostics`.

## Используемые технологии

- JavaScript (CommonJS);
- Node.js runtime, предоставляемый средой расширений VS Code;
- VS Code Extension API;
- `TreeDataProvider`-совместимый провайдер дерева;
- API диагностик `vscode.languages.getDiagnostics()` и событие `vscode.languages.onDidChangeDiagnostics`.

## Требования

- установленный Visual Studio Code;
- Node.js — для разработки и запуска проекта в среде разработки;
- языковое расширение или инструмент, который публикует диагностики для открываемого языка, если требуется увидеть ошибки этого языка.

Расширение не выполняет собственный анализатор исходного кода. Оно отображает диагностики, которые предоставляет VS Code и подключённые языковые инструменты. Поэтому набор обнаруживаемых проблем зависит от языка, установленных расширений и их настроек.

## Запуск в режиме разработки

1. Склонируйте репозиторий или откройте папку проекта в VS Code.
2. Убедитесь, что в `package.json` корректно объявлены команды и представление `errorRadar.diagnostics`.
3. Откройте `extension.js`.
4. Нажмите `F5`, чтобы запустить Extension Development Host.
5. В тестовом окне откройте файл, для которого языковой инструмент предоставляет диагностики.
6. Откройте панель **Explorer → Error Radar**.
7. Раскройте файл и нажмите на сообщение диагностики, чтобы перейти к проблемному месту.

Для запуска команды подсчёта откройте палитру команд (`Ctrl+Shift+P`) и выберите **Error Radar: Check Diagnostics**.

## Ограничения

- Error Radar отображает только диагностики, опубликованные VS Code и языковыми расширениями.
- Не все ошибки времени выполнения обнаруживаются статически. Например, обращение к несуществующему элементу массива может проявиться только при запуске программы.
- Если для языка не установлен или не активен инструмент диагностики, панель может быть пустой.
- Расширение не исправляет код автоматически; оно помогает найти диагностируемые места.
